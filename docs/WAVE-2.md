# Vague 2 — analyse des six scores

Date : 21 août 2026  
Sources : MusicXML + PDF (5) ; MIDI + PDF (Stay with us)  
Règle : basse étrangère jamais réinterprétée comme extension. ATR = Approche → Tension → Résolution.

Les six fichiers suffisaient. Les MXL n’ont pas de balises `<harmony>` : la grille est lue dans les hauteurs et la basse, puis corrigée à l’œil sur la partition. Les labels automatiques par mesure restent des *guides* ; la lecture formelle ci-dessous est la source de vérité.

## 1. 3 anges pour une fretless

| | |
|---|---|
| Armature | 2 bémols — Bb / sol mineur |
| Mètre / tempo | 4/4 · ♩=110 |
| Mesures | 99 |
| Effectif | Basse fretless, violon, alto, cello, octobasse |

**Forme.** A (1–17) exposition Gm/Eb/Bb · B (18–38) développement A7sus4 / C9 / Bbm · C (39–53) visitation majeure C/F/Am · D (54–73) lointain Ab/Fm · A′ (74–87) récap quasi littérale (m.74 ≈ m.4) · coda Bb (88–99) sur **Bbsus2**.

**Lecture.** Premier traité de basse chantante du corpus. La fretless est le protagoniste ; les quatre cordes sont l’auréole. Basses étrangères : F sous Cm, A sous Fmaj, D sous Ebmaj9, Ab sous Fm11. La récapitulation existe — les trois anges reviennent. Cadence ouverte : Bbsus2, pas un Bb majeur sec.

**ATR.** Approche C7sus4/F, Gm7, Ebadd9, Fmaj/A, Ebmaj7 · Tension A7sus4, C9, Fm11, Abmaj7, Cmaj9/Ab · Résolution Ebmaj7 en récap, Bbmaj9/F, Bbsus2.

## 2. AFRI-CAN Reunion — 28-05-2021 (parent du MIDI 17-02-2022)

| | |
|---|---|
| Armature | 3 bémols — Eb / do mineur |
| Mètre / tempo | 4/4 · ♩=78 (MIDI 2022 : 86) |
| Mesures | 110 (MIDI 2022 : ~88) |
| Effectif | Piano, 2 vlns, 2 altos, cello, contrebasse |

**Forme.** A (1–17) Fadd9 / Cm / Bb · B (18–48) modal africain + médiante **E majeur** · C (49–80) développement · coda (81–110) vers Bb.

**Lecture.** Deux dates, un organisme. Le score de mai 2021 est plus lent et plus long. Même ADN d’ouverture que le MIDI déjà lu en vague 1 : Fadd9 → Cm11 → F7sus4 → Bb. Aile modale : Fm11, Dbmaj7, Gbmaj7, Ebm, Ab. Contre une armature en mib, mi majeur (mes. 6, 47, 52) est une médiante chromatique — un personnage, pas une modulation. Cadence Bb (dominante-comme-maison, déjà dans Pour Toi Ma Belle).

## 3. All She Give me

| | |
|---|---|
| Armature | 2 dièses — ré majeur |
| Mètre / tempo | 4/4 · ♩=110 |
| Mesures | 36 |
| Effectif | 4 guitares nylon + basse médiator |

**Forme.** A (1–8) pédale D · A′ (9–16) · B (17–24) · coda-lift (25–36) G/C lydien.

**Lecture.** Première chanson en ré, premier ensemble de guitares. Voix intérieures chromatiques ; dallage Dadd9 / Dmaj7. Basse étrangère signature : **Dmaj7/Db** (majeur sur sensible). Bb récurrent = bVI, porte pop-soul. Huit dernières mesures : Cmaj13#11 et Gmaj13 — gratitude lydienne. Fin **Daug** : le don reste ouvert.

Fenêtre lydienne Cmaj13#11 (mes. 12 et 87). Harpe = étincelle absente du MIDI. Fin Dsus4 / sol mineur : le chapiteau reste ouvert.

## 5. On her way home

| | |
|---|---|
| Armature | 3 dièses — la majeur / fa# mineur |
| Mètre / tempo | 4/4 · ♩=110 |
| Mesures | **12** |
| Effectif | Piano, 2 vlns, alto, violon pizz, cello, contrebasse |

**Forme.** Vignette : pédale A (1–5) · Dmaj9#11 (6) · retour (7–12) cadence I/5.

**Lecture.** Score complet le plus court, l’un des plus révélateurs. Pédale A = la route. Am9 puis Amaj13 sur la même basse : papillotement majeur/mineur (règle Softly, pas une humeur). Mes. 6 Dmaj9#11 = la maison vue du chemin. Dernier accord **Amaj7/E** : elle n’est pas encore rentrée — dominante à la basse, tonique dans l’air.

Progression :

```
1–5  Am9 · Amaj13 · Aadd9 · F#m11 · F#m11   (pédale A)
6    Dmaj9#11
7–9  Am9 · Amaj13 · Bm13
10–12 C#7sus4 · F#m9 · Amaj7/E
```

## 6. Stay with us, my friend

| | |
|---|---|
| Armature | Do (C) — couleurs Am / Dm |
| Mètre / tempo | **3/4** · ♩=110 |
| Mesures | ~81 |
| Effectif | Piano, 2 vlns, 2 altos, cello, contrebasse |

**Forme.** A (1–16) invitation · B (17–28) · C (29–48) lointain Db/Gb/Abm · A′ (50–81) retour, **Asus4** ouvert.

**Lecture.** Seule valse du corpus. Ouverture Fadd9/G = invitation (IV sur V). Le 3/4 laisse respirer le rythme harmonique : ATR à la phrase, pas à la mesure. Patch lointain (29–48) = chromatisme Flying Circus dans une valse. Retour mes. 50 (Dm11 / Am9). Quatre derniers : A7/C# · Gm13/D · Bbmaj13#11 · Asus4 — une tension qui demande à l’ami de rester.

## Ce que la vague 2 change

1. Flying Circus n’était pas en do, et pas à 79.
2. AFRI-CAN 2021 est le parent plus long/lent du MIDI 2022.
3. Première valse, première fretless, premier ré, premier la.
4. La récapitulation est un vrai dispositif (3 anges, Flying Circus, Stay with us).
5. Cinq scores sur six à 110. AFRI-CAN reste à 78.
6. Cadences ouvertes : Bbsus2, Daug, Amaj7/E, Asus4, Dsus4/Gm.
7. Basse étrangère confirmée sur partition, pas seulement sur MIDI.

Règle inchangée : **la basse n’est jamais réinterprétée comme extension.**
