# Méthode

1. Extraire l’effectif, l’armature, le mètre, le tempo, le nombre de mesures (MusicXML).
2. Lire la basse (partie basse / contrebasse) comme **basse étrangère** : jamais réinterprétée comme 9e, 11e ou 13e.
3. Nommer l’accord supérieur (tierces + 7e + tensions) indépendamment de la basse.
4. Corriger à l’œil sur le PDF (voix de passage, 16es, clusters).
5. Découper la forme par récap, pédale, médiante, cadence.
6. Étiqueter ATR : Approche / Tension / Résolution (et Pédale si une basse tient).

Ce n’est pas un roman numeral schoolbook. C’est la grammaire des 42 harmonies.
